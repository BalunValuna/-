# The Long Road 2 — план переработки

Исходник прошлой версии — только минифицированный бандл (`The long drive opus 5.5 game.html`).
Игра переписывается с нуля в модульном виде (Vite + three.js + Rapier), сборка — один HTML-файл.

## Требования пользователя (чек-лист)

### 1. Машина (главная задача)
- [ ] Модель с нуля, стиль ~2010 года (не 199x), новее и лучше референса.
- [ ] Иерархия: каркас → корпус → обшивка (крыша, двери, крылья, капот, багажник, бамперы,
      лобовое и заднее стекло, фары, фонари) — всё снимается/ставится.
- [ ] Без щелей-«разломов» между наружными и внутренними панелями, ничего не торчит.
- [ ] Салон: передние и задние сиденья, торпеда, руль, приборы, багажник с содержимым.
- [ ] Свет: фары хорошо освещают дорогу, плафон салона работает, подсветка приборов.
- [ ] Инструмент-критик: рендер с закрытым/открытым капотом, изнутри, автоматические проверки
      (просветы, видимые изнанки, пересечения) + ручной разбор картинок.

### 2. Интерфейс
- [ ] Новый визуальный стиль (не «нейрослоп»), единый для всех экранов.
- [ ] Никаких уродливых скроллбаров; нет перегруженных и лишних элементов.
- [ ] Статистика/журнал — удобный экран-дашборд, а не список.
- [ ] Главное меню, пауза, настройки — переработаны. Кнопка «Мультиплеер» (заглушка).
- [ ] Убрать бесполезные всплывающие плашки; оставить полезное (туториал сборки машины).

### 3. Взаимодействие
- [ ] Детализированные руки от первого лица, предмет в руке виден и синхронизирован с рукой.
- [ ] Перетаскивание предметов как в оригинале (физически, руки тянутся к предмету).
- [ ] Модель персонажа целиком (для будущего мультиплеера), себе видны только руки.
- [ ] Подсветка наводимого предмета/детали/слота установки.

### 4. Физика
- [ ] Подвеска: пружины, амортизаторы, стабилизаторы, видимый ход колёс.
- [ ] Переворот только на высокой скорости при резком манёвре с учётом сцепления (дождь, песок),
      без переворотов «на ровном месте».

### 5. Мир
- [ ] Дома: новая планировка, интерьеры; мебель детальная и в вариациях (полки, шкафы…).
- [ ] Модели персонажей, монстров, животных — переделать.
- [ ] Сюжет переработать.
- [ ] Окружающий мир детальнее.

### 6. Новая игра
- [ ] Экран настроек перед стартом: сложность, режим старта (с голого каркаса / готовая машина / гараж).

### Ограничения
- Звуки не переделываем (переносим как есть). Мультиплеер не реализуем.
- Без субагентов.

## Архитектура

```
src/
  core/      математика, RNG, шум, ввод, настройки, i18n, сохранения
  geo/       процедурная геометрия: SDF, Surface Nets, обрезка полем, кромки панелей
  render/    рендерер, материалы, небо, пост-обработка, подсветка
  physics/   обёртка Rapier, машина (подвеска, шины, трансмиссия)
  car/       дизайн, кузов, панели, салон, механика, свет, детали и слоты
  player/    контроллер, руки, аватар, переноска предметов
  world/     рельеф, дорога, объекты, дома, мебель
  creatures/ животные и монстры
  ui/        меню, HUD, журнал, настройки
  audio/     синтез звука (перенесён из старой версии)
  dev/       лаборатория машины (lab.html) и API для критика
tools/
  critic/    рендер ракурсов + автопроверки модели (playwright + swiftshader)
```
